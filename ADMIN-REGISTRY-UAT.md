# Admin registry access checks

Restart the local Permit backend, then refresh the browser with Ctrl+F5.

1. **Admin without assignments:** Sign in as an admin with no assigned stations. Open Building Permits and Occupancy Permits from the sidebar. Open Details in each registry. All station statuses, dates and remarks must remain view-only; there should be no station Edit button. Existing inspection entries and saved requirements should be readable, with their editing controls hidden or disabled.
2. **Assigned admin:** Using the existing IT account-management screen, assign Electrical to the admin account, then refresh that admin's permit details. Click Edit. Electrical must be editable; Sanitary and other stations must remain view-only. Save an Electrical status/date/remarks change and refresh. It must persist and show the admin's profile display name. Repeat for Building, a Building sub-permit, and Occupancy.
3. **Permission revoked after loading:** Leave the admin's Electrical edit open. Remove that assignment through account management, then try to save from the old admin tab. The server must reject the save without changing the record. Refreshing must remove the edit controls.
4. **Existing workflows:** From either registry, use the sidebar to return to the admin Overview and review screens. Verify normal request approval/rejection and final project review still work. Sign in as an operator to confirm its assigned-station edits, creation, inspections and checklists still work. Sign in as IT to confirm its account-management screen remains unchanged and direct registry URLs still return it to the IT workspace.
5. **Admin single deletion:** Create disposable test records in each registry. As an admin, click Delete on one. Confirm that the dialog names the correct permit and explains permanent deletion. Cancel first and check that the record remains. Confirm deletion, then refresh: only that permit and its dependent records should be gone, with no approval request created. Its deletion must appear in admin activity history under the admin's display name.
6. **Admin Delete All:** Use disposable records in one registry. Click Delete all permit records and verify the entire-registry count, including filtered-out records. Cancel once; nothing should change. Then type `DELETE ALL` and confirm. A deletion-success notice should appear and the registry should empty immediately. The other registry must retain its records. Repeat for the other permit type.
7. **Operator deletion still requires approval:** As an operator, delete one test permit or submit Delete All. The message must say the request was sent to the admin, and the permits must remain until approval. If an admin directly deletes records covered by an older operator bulk request, that old request must leave the pending queue and remain in history as superseded.

No database migration is needed. Assignments use the existing `permit_station_assignments` table. Superadmin accounts cannot receive engineering station assignments; the existing IT account-management permissions stay in place.
